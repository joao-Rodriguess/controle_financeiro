# Fluxo - Sistema de Gestão Financeira

Esta é uma aplicação moderna de gestão financeira desenvolvida com HTML, CSS e JavaScript puros.

## Funcionalidades

- **Dashboard Interativo**: Visualize suas receitas, despesas e saldo atual em tempo real.
- **Gráficos Dinâmicos**: Acompanhe o fluxo de caixa e a distribuição de gastos por categoria usando Chart.js.
- **Lançamentos Simples**: Adicione e remova transações facilmente.
- **Simulador de Previsões**: Projete sua saúde financeira ajustando a porcentagem de gastos e veja o lucro acumulado para os próximos 12 meses.
- **Persistência Local**: Seus dados são salvos automaticamente no seu navegador via `localStorage`.

## Como Executar

1. Basta abrir o arquivo `index.html` em qualquer navegador moderno.
2. Recomendado: Usar a extensão "Live Server" no VS Code para uma melhor experiência.

## Tecnologias Utilizadas

- **HTML5/CSS3** (Variáveis CSS, Grid, Flexbox, Glassmorphism)
- **Vanilla JavaScript** (ES6+)
- **Chart.js** (Visualização de dados)
- **Lucide Icons** (Iconografia moderna)
- **Google Fonts** (Fonte Outfit)
