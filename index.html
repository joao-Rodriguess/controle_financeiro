Configurar Google Sign-In

1
Acesse o Google Cloud Console

Vá para console.cloud.google.com/apis/credentials

2
Crie um projeto

Clique em "Criar Projeto", dê um nome (ex: "Fluxo App") e confirme.

3
Configure a Tela de Consentimento

Vá em "Tela de Consentimento OAuth" → Tipo "Externo" → preencha apenas o obrigatório.

4
Crie as Credenciais

Vá em "Credenciais" → "Criar Credenciais" → "ID do cliente OAuth" → Tipo "Aplicativo da Web".

5
Adicione a Origem Autorizada

Em "Origens JavaScript autorizadas", adicione: http://localhost:8080

6
Copie o Client ID e cole abaixo

O Client ID termina com .apps.googleusercontent.com

⚡ Só é necessário configurar uma vez. O Client ID ficará salvo.
